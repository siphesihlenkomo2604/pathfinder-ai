# PathFinder AI

Build a modern, fully functional web application prototype named PathFinder AI (an AI Workplace Productivity Assistant for job seekers and professionals).

Design System & Styling Specs

Palette: Soft, warm neutrals using Tailwind CSS.

Main background: #FDFBF7 (Light Cream)

Cards/Containers: #EFE8DE (Rich Sand/Nude)

Borders/Dividers: #D8C8B8 (Warm Beige)

Primary Text/Headers: #2C221E (Espresso)

Active Buttons/Accents: #8C6D53 (Warm Gold/Taupe)

Layout: SaaS-style dashboard featuring a fixed left sidebar navigation, clean card-based components, smooth rounded corners, interactive loading states, and full responsive design across desktop and mobile.

Footer Banner: A persistent, subtle Ethical AI Disclaimer reading: "AI-generated content may require human review."

Navigation & Core Pages

Smart Email Generator: Form inputs for Job Title/Role, Recipient, Audience, and Tone (Formal, Persuasive, Enthusiastic). Outputs a structured draft in a text box with an interactive "Copy to Clipboard" button.

AI Task Planner: Input fields for available daily hours and priority focus. Displays a generated, interactive schedule grid with prioritized tasks, actions, and deadlines.

Job & Scam Analyzer / Research Assistant: A text area to paste job descriptions or research notes. Outputs a key requirements summary, research insights, and a clear "Scam Risk Check" score/analysis.

Meeting Notes Summarizer: Interface to paste raw text or transcripts and output bulleted key points, action items, and clear deadlines.

Career Mentor Chatbot: An interactive, conversational chat UI tailored for interview practice and real-time career guidance.

Technical Requirements

Implement structured prompt logic for all generator and analyzer features.

Provide dynamic UI state changes (loading spinners, copy confirmations, active tab switching).

Ensure clear, professional outputs for every AI interaction.
